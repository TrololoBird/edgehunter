Порядок проверки: повтор и журнал → геометрия → стратегии построчно → совпадение живого и архивного кода → данные →

## Проверено и в порядке

- Повтор журнала: вход по открытию следующей минуты + проскальзывание, стоп при гэпе по открытию, цель — проход на 2 б.п.,
  стоп раньше цели в одной свече, фандинг по расчётам каждые 8 ч, свечи исхода начинаются после сигнальной минуты.
- `net_r` вычитает комиссию из R журнала; R:R в `finish_levels` вычитает издержку из прибыли и добавляет к риску по
  одному разу; цели ставятся перед уровнем на p50 прокола.
- Дневные свечи для выходов Connors / Turtles только закрытые.
- Данные Binance: OI, фандинг, mark совпадают с REST; поминутные покупки / продажи тейкеров совпадают до доллара.
- Демо: стоп по mark-цене reduce-only, цели — лимиты по третям, позиция без стопа сразу закрывается, лимиты
  касаний (eng-46) — по цене линии.
- Исследовательские скрипты импортируются; ссылок на удалённые функции нет.
- `Silver Bullet` берёт первый FVG после выноса (как у ICT).
