# Инвентаризация уровней карты (eng-169, 26.10.2026, коммит 0dc59cb + аудит)

Источник: `zones.py` (`build_raw`, `merge`, `targets`, `stop_beyond`, `support_in`), `config.py` (`ZonesConfig`),
`scanner.py` (стакан), `positioning.py` (Hyperliquid), `levels.py` (fib / range), `scenarios.py` (htf, брифинг).
Сверка определений — по открытым источникам (ссылки в конце). У ICT нет письменного первоисточника: его определения
сверены по вторичным материалам (LuxAlgo, TradingView, MQL5), и это отмечено.

## 1. Как уровни превращаются в план

1. **Сбор** (`build_raw`): сырые уровни всех видов ниже.
2. **Слияние** (`merge`): уровни, чьи диапазоны «тело–фитиль» пересекаются или стоят ближе p50 прокола своего вида, становятся
   одной зоной. Без модели проколов — ближе 0.3 ATR. Ширина зоны не больше 6 ATR; уровень шире стоит отдельной зоной.
3. **Сила зоны** = сумма весов источников; один вид — не больше двух своих весов. **Повторы между разными видами не убираются**:
   один экстремум, прочитанный как свинг 15m, свинг 1h, EQL и минимум дня, даёт 4.0
   (`tests/test_audit_zone_dependence.py`).
4. **Роли**:
   - **препятствие / TP1 / TP2**: первые зоны силой ≥ `min_strength` 2.5 по ходу сделки, цель — ближний край зоны;
   - **TP3**: следующий пул (`POOL_KINDS`) за TP2, иначе следующая сильная зона;
   - **стоп за пулом**: стоп отодвигается за ближайшую зону с видом из `POOL_KINDS` (кроме `liq_est`) или `STOP_SWINGS`, если она
     стоит за инвалидацией в пределах p90 прокола (без модели — 0.6 ATR, риск не больше 3 ATR). Уже снятые (swept) пулы не годятся;
   - **опора отката** (`support_in`): сильнейшая зона силой ≥ 2.5 внутри зоны отката (только оценка, не цель);
   - **HTF-зона** (`signal_book.py:141`): цена внутри зоны с видом 4h / 1d / 1w → подтверждение `htf_zone` (только журнал).
   - Зона только из `liq_est` никогда не бывает целью или якорем (`liq_only`).
5. **R:R** считается до TP1. TP1 ближе нужного → отказ `low_rr`.

Обозначения ролей в таблице: **С** — сила зоны (препятствие, TP1/2, опора отката); **П** — пул (TP3 и «стоп за пулом»);
**Ст** — стоп за ним (`STOP_SWINGS`); **Стр** — структурный (`STRUCTURE_KINDS`, есть «край», за который ставят стоп).

## 3. Сверка определений с источниками

| Вид | Совпадает с источником? | Комментарий |
|---|---|---|
| Свинги (фрактал) | **да** | Уильямс: 5 баров, средний строго выше двух с каждой стороны; подтверждение с лагом 2 бара — в коде так же. У Уильямса фракталы торгуются как пробой по тренду (с Alligator), а не как уровни S/R; использование как S/R — наше. |
| FVG | **да** | 3 свечи, high₁ < low₃. Порог «≥ 10% средней свечи» — наша эвристика (в источниках только «значимый» разрыв). |
| Order block | **да, с вариантом зоны** | Последняя противоположная свеча перед смещением, смещение обязательно (у нас: слом свинга + FVG). Источники рисуют OB от high до low или уточняют до тела / 50% тела; «от open до фитиля» — один из вариантов. |
| Breaker | **да** (исправлено 26.10 после перепроверки) | По вторичным источникам breaker требует: (1) снятия ликвидности, (2) слома структуры, (3) пробоя OB. В коде OB возникает только тогда, когда смещение **закрылось** за последним подтверждённым свингом, — это уже снятие ликвидности за ним; потом закрытие за дальним краем OB даёт (2) и (3). Первая версия этого документа ошибочно называла это расхождением. |
| BPR | **да** | Пересечение двух противоположных FVG, сторону задаёт более поздний. Источники расходятся, нужен ли «инвертированный» первый FVG; код его не требует. |
| Equal highs / lows | **да** | Пул ликвидности у равных экстремумов. Фиксированного допуска нет ни у кого; ATR-допуск — распространённая практика. Сами источники оговаривают, что как цели эти пулы не проверены. |
| Value area | **да** | 70% и добавление по две строки — вариант для объёмного профиля (в исходном Market Profile по TPO — по одной). 70% — конвенция (~1 σ). |
| HVN / LVN | **да** | HVN — принятая цена, цена там «вязнет»; LVN — цена проходит быстро. В коде LVN помечен как цель / край, не опора — это согласуется с источниками. |
| Круглые числа | **частично** | Osler (NY Fed, J. Finance 2003, валюты): take-profit скапливаются **на** круглых числах (поэтому там развороты), stop-loss — **сразу за** ними (поэтому за ними ускорения). Код делает `round` пулом и отодвигает **наш** стоп за круглое число, то есть в ту полосу, где по Osler скапливаются стопы и начинаются каскады. Плюс собственный замер проекта на крипте: держат хуже случайного. |
| Сессии | **да** | Токио 9–18 JST, Лондон 8–17, Нью-Йорк 8–17 по местному времени, с переходом на летнее время — так в источниках. |
| PDH / PDL / PWH / PWL | да (определение) | Прошлые экстремумы периода — стандарт (Murphy). Замечание: текущие day high / low и экстремумы сессий записаны тем же видом `pdhl` и наследуют роль «пула» и вес PDH / PDL, хотя это другие события (незавершённый период). |
| `liq_est` | **нет источника** | Смесь плечей 10/25/50/100 и веса 0.3/0.35/0.25/0.1 — допущение. Форвард-тест проекта — в пределах шума. Вес уже снижен до 0.5, как стоп-пул не используется. |
| VWAP / fib / opens / htf / pmhl / year | определения стандартные | Определения обычные, веса и роль препятствия не измерены. |

## 4. Что из этого следует (без изменений в коде)

1. ~~Breaker без снятия ликвидности~~ — ошибка первой версии: снятие заложено в определение OB (закрытие за свингом).
2. **Исправлено в eng-169e — зависимые источники**: свинги 15m / 1h, `equal`, `pdhl` (включая текущий day high / low) и `flip`
   часто строятся на одной свече и складываются в силу зоны.
3. **Методологический пробел — веса старших ТФ**: 1.5–4.0 без замера; 110 из 168 TP1 за 3 дня опираются на них.
4. **Исправлено в eng-169e — стоп у круглых чисел**: круглое число больше не якорь стопа и не стоп-пул (по Osler там
   скапливаются чужие стопы); как цель TP3 оно осталось (там скапливаются тейки).
5. **`pdhl` смешивает завершённые и незавершённые экстремумы** — оставлено сознательно: за текущим максимумом / минимумом дня
   так же лежат стопы, стратегия sweep торгует именно их снятие, вид `pdhl` используется стратегиями, брифингом и моделью
   проколов; разделение без замера сломало бы распознавание выносов. Вес 1.0 у всех видов этой группы одинаковый.
