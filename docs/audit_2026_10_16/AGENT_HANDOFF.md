**База аудита — `f386ec3b9e34131ff45b1e65721a7fe3f48542e2`.** В этой ветке добавлены только материалы `docs/audit_2026_10_16/`; торговые исходники, конфигурация, logic_version, состояние бота и аккаунты не менялись.

При публикации обнаружен новый `origin/master`: **`47207badd27c8dd7f75b5d0c1c7f77929db1d3a0`**. Нельзя переносить вывод «баг есть» с f386ec3 на master без проверки diff и воспроизведения. Удалённая ветка могла продвинуться ещё дальше после публикации.

## Что уже сделано

- Разобраны 20 классов, 14 семейств, 40 setup-названий, все 28 файлов `strategies/`, включая shadow/disabled варианты.
- Сопоставлены docstrings, параметры, формулы, последовательность событий, hard/shadow подтверждения, таймфреймы, единицы и полнота данных, входы, стопы, цели и сопровождение.
- В каталоге 30 групп источников; первичные материалы отделены от вторичных изложений и поисковых фрагментов. Полный текст оригинальных ICT-видео недоступен; точная формула Pring и точный первичный event-rule VA80 не установлены.
- REPORT содержит A01–A18; STRATEGY_COMMON — S01–S11. Это не 29 независимых дефектов одного типа: есть пересечения, ошибки кода, нарушения собственного контракта, сознательные адаптации и недоказанные приписывания.
- Существующие 75 тестов прошли на Python 3.12/3.14. Новые 10 контрпримеров стратегий прошли на обеих версиях; предыдущие 12 технических примеров сохранены. Это доказательство отдельных путей, не прибыльности и не live-исполнения.
- SHA256 293 исходных tracked-файлов совпали с началом аудита. Внешние API бирж и production DB в диагностических примерах не используются.

## Команды воспроизведения

Ниже команды для **изолированной исходной базы**, а не для работающего VPS. Если репозиторий уже скачан, не клонируй поверх него и не сбрасывай чужие изменения. Имена worktree/venv выбери свободными, если эти уже существуют.

```bash
cd ../pump-audit-baseline
git rev-parse HEAD
git diff --stat f386ec3b9e34131ff45b1e65721a7fe3f48542e2 -- . ':!docs/audit_2026_10_16'

python3.14 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python docs/audit_2026_10_16/reproduce.py
.venv/bin/python docs/audit_2026_10_16/strategy_reproductions.py

```
