## 3. Стратегии (каждая -> журнал/реплей с правилом до запуска)
| Стратегия | Проблема (аудит + журнал) | Изменение |
|---|---|---|
| BB W-BOTTOM (-11.7R) | цель не measured move, BB1 по II% | цель = высота W; таker-данные вместо II%; до теста - снять с демо |
| ORB (UP -3.7R) | стоп у противоположного края (широкий), окно на минутах фандинга | стоп = середина диапазона; фильтр NR4/NR7; сдвиг окна от фандинга |
| AUCTION / VA80 LONG | VA текущей недособранной сессии | VA80 от предыдущей завершённой сессии / VA прошлого дня |
| Trendline | 2 касания, ретест по старому значению | 3 касания; ретест по значению линии в момент касания или горизонтальный уровень; короче TTL; стоп за свинг ретеста |
| PO3 (+) | нет фильтра азиатского диапазона | требовать узкую Азию (сохранить плюс, проверить) |
| IMPULSE | EMA20-fallback ломает геометрию | исправить fallback; качество ноги по OI + spot CVD |
| Silver Bullet (SHORT -3.7R) | TP1 < 1.5R | TP1 на следующий draw, если R < 1.5 |
| SWEEP HIGH (-3.0R) | стоп за пулом выбивают | вариант «ждать свип»: вход после снятия пула |
| Connors | все монеты | только мейджоры; фильтр ликвидаций/фандинга |
| DUMP BOUNCE | нет позиционирования | фильтр фандинг/OI |
| Cup & Handle | пороги в % | в единицах ATR или на 4ч |
| Supply/Demand | нет частичного TP, глубина подхода | частичный TP; проверка глубины захода в зону; при возврате профилей инвертировать atr_high |
| Wyckoff FLUSH/SQUEEZE | нет HTF контекста | HTF-фильтр; оценка по shadow-статистике |
| OI BUILD (-3.3R) | сигнал не отделяет набор от закрытия | переработка или снятие с демо |
