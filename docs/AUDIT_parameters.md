# Аудит параметров `config.py` (eng-57, 2026-10-04)

Каждый торговый параметр отнесён к одной из категорий:

| Метка | Что значит |
|---|---|
| **ИСТ ✓** | Из первоисточника метода, значение сверено веб-поиском |
| **ИСТ ~** | Из источника, но наше значение или применение от него отходит |
| **ИЗМ** | Измерено нами: на архиве или на живом журнале, есть файл исследования |
| **ПОРТ** | Взято из чужого робота-образца как есть; первоисточника метода за ним нет |
| **НАШ** | Выбрано нами без измерения и без источника (гипотеза, «на глаз») |
| **ТЕХ** | Технический: трафик, лимиты API, память. На сигналы не влияет |
| **МЁРТВ** | Не читается нигде в коде бота |

Сетевые и технические параметры (`WSConfig`, `RestConfig`, `DepthConfig.sockets`, `recorder`, `logging` и т.п.) —
это **ТЕХ**. Они подобраны по замерам трафика и лимитам Binance, ниже не разбираются.

## 1. Мёртвые параметры (42 шт.) — не читаются ни одним модулем бота

Проверено поиском по всем `*.py`, включая динамический доступ (`getattr` по строке) — его нет.

- **Удалённые в eng-35 системы:**
  - Third Eye: `te_cci_length`, `te_sl_pct`, `te_tp_pct`, `thirdeye_ttl`;
  - fib05: `fib05_ttl`;
  - Bomberman: `bomberman_ttl`;
  - CSI: `csi_*`, 9 шт.;
  - OI-робот: `oi_1h_threshold`, `oi_price_ratio`, `oi_sl_pct`, `oi_tp_pcts`, `oi_cooldown_sec`, `oi_structure_filter`, `oi_accum_ttl`.
- **Отдельные SMT и absorption (теперь подтверждения):** `smt_min_rr`, `smt_fallback_rr`, `smt_sl_buffer_atr`, `smt_ttl`, `absorption_ttl`, `absorption_zone_atr`.
- **Старый 15m breakout (теперь Turtles):** `breakout_measured_moves`, `breakout_min_move_atr`, `breakout_zone_atr`.
- **Прочее:** `sweep_zone_atr`, `accumulation_zone_max`, `auction_fallback_rr` (fallback-цель убрана в eng-41), `tl_min_rr`, `ltf_minutes`, `rvol_micro_burst_threshold`, `avg_minute_share`, `tier2_evict_idle_sec`, `max_concurrent_trades`, `reconnect_delay`, `max_reconnect_attempts`.

## Итоги

- Из 469 параметров **42 мёртвых**; около 150 — технические (трафик, лимиты, память).
- Сверено с первоисточником **около 25**, из них **8 с отступлениями**. Главные отступления:
  - чашка с ручкой на 1h/4h вместо дневок и недель;
  - Connors < 10 вместо < 5;
  - выход Connors на 10-й день не подтверждён;
  - точка отсчёта Stretch в ORB неоднозначна в источниках.
- **Измерено нами — около 15**: пробой уровней, z-пороги Tier-0, каскад $200k, dump-bounce, `liq_est`, недельная EMA, порог $3M.
- **Портировано из роботов-образцов без первоисточника — около 40**: все `tl_*`, `auction_*`, `sd_*`.
- **Остальные ~170 торговых — наши гипотезы**: веса зон, пороги детекторов, R:R 2, тайм-стопы, оценка ликвидаций, фазы A–F. Журнал пишет источник каждого решения, поэтому их можно проверить, но пока ни один не доказан.
- Найдены **две несогласованности**:
  - пороги перегретых шортов: −0.01% и −0.05%;
  - `anomaly_quantile` 0.1% в коде против 0.05% в документации.
