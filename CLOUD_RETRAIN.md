---

Ты работаешь с репозиторием `pump` (Microstructure Scanner, см. CLAUDE.md — прочитай его целиком, особенно разделы
«Current registry (eng-43)» и заметки eng-28…eng-43 в конце, и скилл `research-findings`). Отвечай по-русски. Бот
здесь НЕ запускается (нет живых данных и ключей) — только архивная работа на публичном архиве Binance
(data.binance.vision). Код сигнальной логики НЕ меняй: задача — измерить текущую логику и переобучить модели; найденные
баги записывай в отчёт, правь только исследовательские скрипты, если они не работают.

Правило вердикта (записано ДО прогонов, менять нельзя): стратегия «работает» только если её средний R после издержек
> 0 И на развитии, И на отложенной выборке, а 90% кластерный бутстрэп-интервал отложенной выборки > 0, и
«система − плацебо» на отложенной выборке > 0. Периоды: развитие 2025-04-01 … 2026-03-31, отложенная 2026-04-01 …
2026-09-30 (если архив короче — сдвинь, но запиши это до запуска).

1. Окружение: `py -3.14` / `python3.14`, `pip install -r requirements.txt`. Проверь `python -m pytest tests -q`.
2. Модель проколов без заглядывания вперёд:
   `python research_overshoot.py --end 2026-03-31 --model-out models/overshoot_pre.json`, затем во всех прогонах
   `PIERCE_MODEL=models/overshoot_pre.json`.
3. Прогоны (с плацебо где скрипт поддерживает, 100 монет, 2 воркера; каждый пиши в research/*.md):
   - `research_cards.py` — sweep (вкл. условия ICT: зона 1h+, дискаунт/премиум), Wyckoff spring/UTAD;
   - `research_maniac.py` — supply/demand (4h зоны + кривая), auction, trendline (1h), Bollinger W/M;
   - `research_turtle.py --start 2023-10-01 --end 2026-09-30 --holdout 2025-10-01 --coins 100` (уже был на 60
     монетах: развитие +0.50R, отложенная −0.17R — research/turtle.md);
   - если времени хватает: напиши простые архивные проверки для `cup_handle` (strategies/cup_handle.py), `connors`
     (дневки), `orb` и `value_area` (strategies/classic.py), `pump` (strategies/pump.py: без OI/спота в архиве —
     отметь это) по тому же правилу; детекторы импортируй из strategies, не копируй.
4. Переобучение P(edge): `python pretrain.py --months 6`, затем `python ml_eval.py` на результате. P(edge) остаётся
   теневым, пока AUC вне выборки и Edge верхнего дециля не лучше базовой частоты.
5. Итог: `research/validation_eng43.md` — таблица по каждой стратегии (сделок, R развитие / отложенная, интервал,
   плацебо, вердикт по правилу), что не удалось проверить на архиве и почему, найденные баги. Закоммить отчёты,
   `models/pretrained.pkl` (если прошёл ml_eval; `*.pkl` в .gitignore — `git add -f`) и `models/overshoot_pre.json`,
   запушь в ветку `retrain-eng43`.
