## Исправленные баги в скриптах

1. `research_turtle.trades` (используется в research_pools.py): на «мёртвых» контрактах (делистинг / расчёт, цена не
   меняется) N ≈ 1e-17 цены, R взрывался до −1.9e15 и портил терцили пулов. Теперь дни с N < 0.01% цены пропускаются
   как отсутствие данных. Пулы пересчитаны после исправления.
2. `research_daily_methods.py`: группа «ORB без NR4 / NR7» всегда была пустой — `narrow_range` возвращает numpy bool, а
   сравнение `is False` для него всегда ложно. Исправлено; сравнение NR-фильтра теперь посчитано.
3. `research_replay_report.py`: читал только `run/*/cards.parquet`; при параллельном запуске replay (один каталог на
   процесс) файлы лежат глубже — glob сделан рекурсивным.
4. Новый скрипт `research_meta_replay.py` (задача 8) написан и закоммичен с правилом в docstring до запуска.

`python -m pytest tests -q`: 70 passed. `ruff check --select F` чист для всех изменённых / новых файлов; 17 старых
замечаний (неиспользуемые импорты в research_cards.py, research_maniac.py, tests/test_infra.py, tests/test_runtime.py)
были в master до этой сессии и не трогались.

## Что не удалось / оговорки

- Контейнер один раз перезапускался: претрейн, replay и дневные методы перезапущены (претрейн продолжил по кэшу строк,
  replay пересчитан с нуля). Окно претрейна сдвинулось на день (2025-10-09..2026-10-04) из-за смены даты.
- В replay **нет ни одной строки** ORB, OI SIGNAL, PO3, CUP HANDLE, а также каскадных сетапов (ликвидаций в архиве
  нет). Для ORB / OI SIGNAL / PO3 / CUP причина в этой сессии не исследована — их архивной оценки нет.
- Wyckoff: 473 карточки созданы, но ни одна не вошла в сделку (входы только vetoed: low_rr, no_spring_test).
- Cup with handle (дневки): 17 сделок — судить нельзя; разбивка глубины в недельных ATR (план 2.10) не напечатана из-за
  малого числа.
- Turtles в replay: результат по карточке (final_r) включает пирамидинг; 8h-реплей журнала (r_tp1) для них
  неинформативен.
- `pretrain_rows.parquet` (вход ml_eval) и данные replay (`data/`) остались в контейнере, не закоммичены по правилам;
  `research/replay_summary.parquet` (2.5 МБ: карточки + входы без f_* признаков) закоммичен.
